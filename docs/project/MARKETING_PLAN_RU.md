# План маркетинга Monte-Neo (внутренний документ)

Дата: 2026-09-26 · Версия продукта: v0.26.0

## 1. Цель и метрики

**Цель на 90 дней:** Monte-Neo — инструмент по умолчанию, который зовут, когда AI-агент написал
торговую стратегию и нужно проверить бэктест.

| Метрика | Где смотреть | Цель к 90 дням |
|---------|--------------|----------------|
| Загрузки PyPI в месяц | бейдж в README, pepy.tech, pypistats.org | 3 000+ |
| Звёзды GitHub | репозиторий | 500+ |
| Установки GitHub Action | «Used by» / dependents | 20+ репозиториев |
| Ловушки от сообщества | issues с меткой `trap` | 10+ |
| Упоминания / ссылки | поиск по имени, обратные ссылки | 5+ статей или постов не от нас |

## 2. Аудитории и сообщения

| Аудитория | Боль | Сообщение |
|-----------|------|-----------|
| Разработчики с Claude Code / Codex / Cursor | агент «нашёл» прибыльную стратегию, а верить нельзя | «Пусть агент сам проверит свой бэктест: одна команда, MCP» |
| Алготрейдеры и кванты | подглядывание в будущее, переподгонка | «Четыре независимых способа поймать утечку + Deflated Sharpe» |
| Проп-фирмы, маркетплейсы стратегий, курсы | поток мусорных стратегий | «Первичный фильтр до человека + подписанный сертификат» |
| Исследователи AI | как честно сравнить агентов | «Honesty Bench: доля ложных открытий по агентам» |

**Одна фраза:** независимый верификатор торговых стратегий, написанных AI-агентами и людьми.

## 6. Риски

- **Громкие цифры без воспроизводимости** убьют доверие → публиковать только то, что воспроизводится кодом из репозитория.
- **Спам в сообществах** → один пост на площадку, с ценностью, без повторов.
- **Ложные тревоги на честном коде** → Trap Suite с честными контролями в CI; быстро чинить присланные случаи.
