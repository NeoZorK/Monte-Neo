# Этап 6 — что делает владелец (внутренний документ)

Всё, что можно сделать в репозитории, сделано в v0.42.0 (см. CHANGELOG). Ниже — шаги, которые требуют вашего аккаунта, решения или публикации от вашего имени. Тексты готовы.

## 1. conda-forge

Рецепт: `packaging/conda-forge/meta.yaml` (версия 0.41.0, sha256 sdist подставлен из PyPI). **Рецепт не собирался** (в среде нет conda-build) — проверит CI staged-recipes.

1. Форкните `conda-forge/staged-recipes` со своего аккаунта.
2. Создайте `recipes/monte-neo/meta.yaml` из нашего файла.
3. Откройте PR, дождитесь проверок и ревью. После слияния появится репозиторий `monte-neo-feedstock`, и вы будете его мейнтейнером (в рецепте указан `NeoZorK`).
4. После этого каждую версию бот conda-forge предлагает сам.
5. Для остальных зависимостей проверьте, что `mcp` и `numba` есть в conda-forge. Если `mcp` нет, в рецепте нужно убрать его из `run` и сделать необязательным (в pyproject он сейчас обязательный) — скажите, я подготовлю выпуск.

## 5. Задачи для участников (черновики issues)

Опубликовать их можно командой «создай issues для участников» — я создам их от вашего аккаунта. Черновики:

1. **Trap: `groupby().rolling()` без сдвига внутри группы** — добавить ловушку и честный двойник.
2. **Trap: `expanding().apply` с будущим индексом** — то же.
3. **Trap: усреднение по всему набору символов до присвоения весов** (утечка среднего рынка).
4. **Honest control: `pd.Grouper(freq="D")` со сдвигом** — контроль против ложных срабатываний.
5. **Lint: правило для `sklearn.preprocessing.*Scaler().fit(x)` до разбиения** — предупреждение, тесты на не-срабатывание.
6. **Adapter: backtrader** — `from_backtrader(strategy)` поверх `from_fills` с анализатором заказов; тесты на имитирующих объектах.
7. **Adapter: Nautilus Trader** — событие `OrderFilled` → `from_fills`.
8. **Docs: пример на реальных дневных данных ETF** — скрипт загрузки и разбор вердикта (в среде разработки нет доступа к рынку, нужен автор с сетью).
9. **Report: экспозиция во времени и вклад символов для наборов инструментов.**
10. **Stats: SPA / White Reality Check для `verify_grid`.**
