Assumptions and limitations

  • Fills at the next bar's open; commission 5.0 bps and slippage 5.0 bps per side.
  • Not checked: determinism (determinism: needs strategy code (signal function)).
  • Not checked: lookahead_truncation (truncation probe: needs strategy code (signal function)).
  • Not checked: lookahead_perturbation (future-perturbation probe: needs strategy code (signal function)).
  • Not checked: external_data (outside data: needs strategy code (signal function)).
  • Not checked: lookahead_static_lint (static lint: no source provided).
  • Not checked: data_independence (needs strategy code (positions only)).
  • Not checked: cost_margin (not profitable after costs).
  • Not checked: delay_sensitivity (not profitable after costs).
  • Not checked: timing_significance (not profitable after costs).
  • Not checked: period_consistency (not profitable after costs).
  • The verifier tests the backtest's methodology on the data given; it does not forecast future returns.
  • The economic rationale of the idea (why it should work) is a human judgement; the dossier gives evidence, not that judgement.
  • Costs, fills and latency are models: queue position and partial fills are not modelled.
  • A strategy that behaves differently when it detects a test can only be caught by the probes it does not detect.
