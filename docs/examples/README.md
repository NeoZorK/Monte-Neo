# Examples

This directory will soon contain standalone scripts and configuration examples for various trading scenarios.

### Planned Examples:
- **`custom_indicator.py`**: How to implement and register a custom indicator template.
- **`headless_workflow.py`**: A pure-python script (no CLI) to download, generate, and save an indicator.
- **`multi_asset_search.py`**: Searching for a single indicator that works across multiple symbols.

### Current Examples:
For now, the best way to see the framework in action is by following the [Quick Start](../guides/quick-start.md) guide using the interactive CLI.
