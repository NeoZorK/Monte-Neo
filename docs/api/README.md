# API Reference

The detailed API documentation is automatically generated from the source code docstrings.

Currently, this folder is empty because:
1.  **Source Code is the Truth**: We prioritize keeping the Google Style docstrings in the `.py` files accurate and up-to-date.
2.  **Automated Generation**: We recommend using `pdoc3` to generate these files on-demand.

### How to generate:
```bash
uv run pdoc src/monte_neo -o docs/api/
```
Once generated, you will find HTML files here representing the full project structure.
