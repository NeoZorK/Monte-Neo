# External Libraries

Monte-Neo leverages high-performance libraries to ensure fast and reliable calculations.

## Core Dependencies

- **numpy**: High-performance numerical computing.
- **pandas**: Data manipulation and analysis.
- **pyarrow**: Fast Parquet I/O.
- **numba**: JIT compilation fallback.
- **mlx**: Apple Silicon GPU-accelerated computing.
- **pybind11**: Seamless C++/Python interoperability.
- **python-binance**: Direct integration with Binance API.
- **ta**: Technical Analysis library for base indicators.

## CLI & Visualization

- **rich**: Beautiful terminal formatting and progress bars.
- **questionary**: Interactive terminal prompts and menus.
- **plotext**: Terminal-based charting.
- **mplfinance**: Professional candlestick charts (external).

## Development

- **pytest**: Robust testing framework.
- **ruff**: Extremely fast Python linter.
- **hatchling**: Modern project management and build system.
